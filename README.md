# Teknic Euchner Website

A responsive website implementation based on the provided Figma design.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Intersection Observer API

## Features

- Responsive navigation
- Mobile menu
- Hero video background
- Product cards rendered from JavaScript data
- Responsive product grid
- Manufacturing image carousel
- Scroll reveal animations
- Smooth scrolling
- Responsive footer
